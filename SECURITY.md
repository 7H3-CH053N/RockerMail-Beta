# Sicherheitslücken melden

Wenn du eine Sicherheitslücke in RockerMail findest, melde sie bitte vertraulich und nicht als öffentliches Issue.

- Auf GitHub: im Reiter **Security** auf **Report a vulnerability** klicken. Die Meldung sehen nur du und wir.
- Per Mail: [alex@promptrocker.at](mailto:alex@promptrocker.at?subject=RockerMail%20Sicherheit)

Beschreib, was du gefunden hast, wie man es nachstellt und welche Version von RockerMail und macOS du verwendest. Wir melden uns innerhalb von drei Werktagen zurück und sagen dir, wie es weitergeht.

Beispiele für Sicherheitslücken: Code aus einer Mail wird ausgeführt, externe Inhalte laden ohne Erlaubnis, Zugangsdaten landen außerhalb des Schlüsselbunds, die KI führt eine Aktion ohne deinen Klick aus.
